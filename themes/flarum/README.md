# Flarum 主题

UPanel 的可插拔主题包，只调整设计 token 和控件质感，不改变布局。

## 安装

把整个 `flarum` 文件夹放到 UPanel 安装目录的 `themes/` 下：

```text
/opt/upanel/themes/flarum/
├── theme.json
├── theme.css
└── README.md
```

然后在 **面板设置 → 外观 → 主题** 中选择「Flarum」。

## 设计来源

- 4px 圆角
- 36px 控件高度
- `system-ui` 优先的系统字体栈
- 灰蓝主色 `#536f90`
- 浅灰控件面，而不是强调描边
